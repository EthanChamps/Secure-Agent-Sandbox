# Security policy

Do not publish credentials, customer data or exploit payloads in public issues. Before publishing a repository from this template, enable GitHub private vulnerability reporting and name a maintainer responsible for triage. Use the repository Security tab to report vulnerabilities privately once enabled.

This initial reference release has no audit or support SLA. Only tested release versions should be deployed. Maintainers should acknowledge reports within three business days, coordinate disclosure, publish affected versions and fixes, and rotate credentials if exposure is suspected.

Security boundaries and known limitations are documented in docs/DESIGN.md. Do not describe passing regression tests as proof of zero ASR.
